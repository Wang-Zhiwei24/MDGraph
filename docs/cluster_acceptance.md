# 真实集群接入验收

此清单区分已经在本机验证的软件流程，与必须在目标集群验证的物理/系统条件。

## 需要用户提供的配置

- SSH 实际主机/IP、端口、用户名与可写绝对工作目录；密钥通过本机 agent/文件使用，不发送到聊天。
- Slurm/PBS 类型、队列/分区、账户、CPU/GPU 资源及 walltime 语法。
- LAMMPS 可执行命令与模块初始化方法；需要时提供匹配的 DeePMD/PACE 插件。
- 初始结构与原子类型顺序、真实模型及模型适用范围。
- 研究目标、温压、系综、时间步、步数与数值检查阈值。

## 首次执行顺序

1. 本地 `prepare`：核对原子数、单位、势文件哈希、type_map 和生成输入。
2. 在集群运行很短的算例，验证 LAMMPS 插件加载、模型读取与资源配置。不能将短算例当成生产科学结果。
3. 不加 `--watch` 提交任务，记录 job ID，退出控制器后 `resume`，验证没有重复作业。
4. 等待完成后核对原始日志、调度器退出状态、轨迹和报告。
5. 按课题设计独立参考验证，再提交正式生产任务。

## 首版未声称完成的验证

- 真实集群 SSH/Slurm/PBS 端到端连接：需要目标集群配置。
- 实际 DeePMD/PACE 模型数值正确性：需要用户模型与参考数据。
- 在线 LLM 请求：需要用户选择模型服务并在本机配置密钥。
- 采样收敛、势函数泛化与材料科学结论：需要额外的独立验证设计。
